# Continuing the project

The original development effort is on indefinite hiatus. Forks and independent continuations are welcome; a response to issues or pull requests is not guaranteed.

- Read README, LICENSE, THIRD_PARTY_NOTICES and art/RIGHTS before reusing files.
- Clearly distinguish original-game material, project additions, AI-assisted concepts and your own changes.
- Use your own compatible game installation. Do not add game binaries, full decompiled classes, runtimes, saves, credentials or private machine paths to the repository.
- Keep the original game installation and your saves backed up. Work on a separate copy/profile.
- Treat numeric balance as provisional and identify any new balance pass as your own work.
- Verify ordinary skill bonuses, item previews, animations, loading with tutorial skipped, dialogs, wheel mouse access, save/load, difficulty re-entry and boss phases when touching those systems.
- Hidden game tests should use 5% sound/music/footstep volume and an isolated application ID. Recorded technical tests do not replace manual playtesting or a full campaign pass.
- If you implement Bullet-time, transfer the existing SATS/ЗПС perks and skills, resource behavior and enemy-stat inspection rather than leaving descriptions disconnected from mechanics.
- The rest of the new-grenade branch was cancelled; it is not a promised backlog.

## По-русски

Можно делать форки и свои продолжения. Автор сейчас не обещает сопровождение, ответы и принятие PR. Сохраняйте указание на помощь нейросети, различайте планы и готовые функции, не публикуйте чужую игру и личные файлы. Баланс не доведён — тестируйте и описывайте собственные изменения честно. Сложности при каждом входе должны оставаться независимыми от глобальной сложности и не сбрасывать сюжет/предметы.
